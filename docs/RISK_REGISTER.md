# Risk register
- Hospital deployment is blocked pending clinical workflow acceptance, IT security review and validated operating procedures.
- Official logo supplied; derivatives must preserve proportions and source.
- Scanner keystrokes cannot distinguish typing from HID scanning; classify as unverified. Hardware COM and vendor SDK provenance require actual device acceptance.
- Manual dispensing policy is disabled by default and requires explicit hospital approval and pharmacist role.
- Cerebro live interfaces absent; adapters fail closed.
- Certificate trust, DNS, database service identity, firewall and encrypted off-server backups require hospital infrastructure.
- Installer upgrades, four physical workstations, actual scanners, service recovery and disaster recovery require on-site validation.
- Unsigned executables may trigger Windows trust warnings; hospital code-signing certificate not supplied.
- New software is not clinically validated merely because automated tests pass.
