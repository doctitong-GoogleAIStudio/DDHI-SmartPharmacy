# Cerebro integration assumptions
No vendor endpoints, database schema, credentials, or write authorization were supplied. Mock adapter only is enabled. REST and read-only database adapter boundaries must fail closed until an approved contract and authorization are implemented. CSV exchange is a local staging mechanism and never proof of vendor acknowledgment.
No undocumented queries, database writes, UI automation or automatic billing. A timeout after posting is an uncertain outcome requiring reconciliation. Production integration requires vendor contract tests and hospital approval.
